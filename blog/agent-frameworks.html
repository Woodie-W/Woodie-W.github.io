Agent 框架与多智能体协作

2026.05
Multi-Agent LLM Agent Framework

从单 Agent 到多 Agent 协作，涵盖 DyLAN 动态团队优化、TOOLMAKER 工具生成与 DataFlow-Agent 数据编排。

为什么需要多智能体协作

现有的 LLM Agent 系统（如 AutoGPT、CAMEL）通常使用固定数量的智能体和静态通信结构。但现实世界中的复杂任务往往需要不同专业能力的组合，且任务需求可能动态变化——就像人类团队会根据项目需要调整成员一样。

另一个值得关注的方向是 Agent 的工具自主创造能力：与其让人类预设工具集，不如让 Agent 自己根据任务需求生成所需的工具。同时，在数据准备领域，LLM 驱动的 Agent 也开始接管原本依赖手工脚本的复杂工作流。

DyLAN：动态 LLM 智能体网络

DyLAN（Dynamic LLM-Powered Agent Network）将多智能体协作过程形式化为时间前馈网络（T-FFN）：每一层代表一个时间步，节点代表参与的智能体，边代表通信。它分两个阶段运行：

  • 团队优化（Team Optimization）：无监督选择算法，基于"智能体重要性得分"从候选池中挑选对特定任务贡献最大的 Agent。
  • 任务解决（Task Solving）：选定的精英团队通过动态通信结构协作，并内置"团队重组"机制——通过 LLM Ranker 剔除低效率成员。

DyLAN 在 HumanEval（代码生成）、WebShop（购物决策）、MMLU（通用推理）和 MATH（算术推理）上验证了其有效性。其核心思想是：效率与有效性的平衡——移除不相关或表现不佳的 Agent，减少计算开销的同时提升最终质量。

TOOLMAKER：Agent 创建工具

TOOLMAKER 探索了一个更激进的方向：让 LLM Agent 自主生成工具，而不是依赖人类预设的工具集。当 Agent 遇到现有工具无法处理的子任务时，它可以编写新的工具函数（通常是 Python 函数），并将其添加到自己的工具库中以供后续使用。

这种"工具自举"（Tool Bootstrapping）能力使 Agent 的工具集可以随任务复杂度动态扩展，突破了传统框架中工具集固定的限制。它代表了 Agent 元能力（meta-capability）的一种重要探索。

DataFlow-Agent：LLM 驱动的数据编排

DataFlow 是一个类似 PyTorch 风格的数据准备框架，提供近 200 个可复用算子（Generate、Evaluate、Filter、Refine 四类）和 90+ 个 Prompt 模板，支持构建 DAG 工作流。其核心创新在于 DataFlow-Agent——一个构建在框架之上的智能编排层。

用户只需用自然语言描述数据需求，Agent 会自动完成三步：算子合成（检索或生成所需算子）→ 流水线规划（组装 DAG 工作流）→ 迭代验证（自我测试和调试）。该框架已在文本、数学推理、代码、Text-to-SQL、Agentic RAG、知识抽取等 6 个领域验证了有效性，其中仅用 1 万条合成数据就超越了用 100 万条开源数据训练的模型。

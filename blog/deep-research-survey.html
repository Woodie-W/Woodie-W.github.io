Deep Research Agents 综述

2026.05
LLM Agent Deep Research Survey

关于 Deep Research Agent 系统的文献综述，涵盖从 RAG 到自主研究代理的演进、代表性系统架构与关键技术。

背景：从 RAG 到 Deep Research

检索增强生成（RAG）是大语言模型获取外部知识的主要手段。传统的 RAG 系统通常遵循一个静态流程：接收查询 → 一次性检索文档 → 拼接到 Prompt → 生成回答。这种方式简单高效，但对于需要多步推理、跨文档综合分析、长文报告撰写的复杂研究任务而言，远远不够。

Deep Research Agent（深度研究智能体）正是在这一背景下诞生的。它不再是被动的"检索-拼接"工具，而是能够自主规划研究路径、动态调整搜索策略、迭代深化理解并撰写结构化报告的智能系统。2025 年以来，OpenAI Deep Research、Gemini Deep Research、Tongyi DeepResearch 等系统的出现标志着这一范式的成熟。

从技术演进角度看，Deep Research Agent 的核心特征包括：(1) 长流程推理，能在数十甚至上百个步骤中保持目标一致性；(2) 自主工具使用，灵活调用搜索引擎、学术数据库、代码解释器等工具；(3) 上下文压缩与记忆管理，在有限上下文窗口中维护关键信息。

代表性系统架构

目前主流的 Deep Research 系统在架构设计上各有侧重，但都建立在 ReAct（Reasoning + Acting）框架的变体之上：

Tongyi DeepResearch：MoE + 推理时扩展

通义实验室的 DeepResearch 基于 Qwen3-30B-A3B（MoE 架构，总参 305 亿，激活仅 33 亿），采用改进的 ReAct 循环：Thought → Action → Observation。模型通过 XML 标签调用 5 种工具：Search、Visit、Python Interpreter、Google Scholar、File Parser。

其核心技术亮点是马尔可夫状态重构：模型不依赖完整历史记录，而是每步将输入重构为"原始问题 + 演进式报告（压缩记忆）+ 最近交互"，从而突破上下文窗口限制。此外，它支持Heavy Mode：部署 N 个并行 Agent 独立探索不同路径，最后由一个合成模型汇总去重。

WebThinker：推理中无缝浏览

WebThinker 的核心创新在于让模型在推理过程中无缝交替进行思考、搜索和写作。不同于传统 RAG 的"先搜完再写"，WebThinker 允许模型在撰写某章节时发现信息不足，暂停写作去搜索，再回来继续。它支持两种模式：复杂问题解决模式（针对 GPQA/GAIA 等难题）和报告生成模式（分章节"搜索-推理-撰写-修改"循环）。

RhinoInsight：检查清单 + 证据审计

RhinoInsight 关注两个被其他系统忽视的问题：规划阶段的模糊性和上下文噪声的累积传播。它引入两个核心模块：可验证清单模块（将模糊需求拆解为清晰可追踪的子目标，引入"批评家"审查）和证据审计模块（结构化管理搜索内容，动态更新大纲，剔除噪声）。这种设计有效防止了"垃圾进，垃圾出"的困境。

A-RAG：分层代理式检索

A-RAG 将检索过程转化为模型与工具的深度交互，提供三层接口：Keyword Search（精确匹配）→ Semantic Search（向量相似度）→ Chunk Read（精读约 1000 tokens）。这模拟了人类"先扫视再精读"的过程。实验显示，即使只用单一工具的 A-RAG (Naive) 也优于大多数复杂的 GraphRAG，且检索的 Token 数更少但准确率更高——"模型越强，代理范式的优势越大"。

关键技术

上下文管理

长流程任务中，上下文窗口是最关键的瓶颈。主流方案包括：(1) Tongyi DeepResearch 的演进式报告压缩，将每步的发现压缩为结构化报告片段；(2) WebThinker 的文档记忆库，分章节管理查到的信息；(3) RhinoInsight 的证据审计模块，主动剔除噪声信息。

工具使用与规划

Deep Research Agent 通常配备丰富的工具集（搜索、浏览、代码、文件解析等）。关键挑战在于自主决策何时使用何种工具。A-RAG 的分层检索接口和 WebThinker 的无缝交替策略代表了两种主流思路：前者将工具选择权交给模型，后者通过工作流编排引导模型的工具使用。

推理时扩展（Inference-Time Scaling）

Tongyi DeepResearch 的 Heavy Mode 展示了"用计算换质量"的思路：部署多个并行 Agent 独立研究，最后汇总。这种策略在理论上可以无限扩展，但需要解决并行结果去重、冲突消解和合成质量等问题。
